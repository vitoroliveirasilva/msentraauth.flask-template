# Glossário

- **App Registration:** cadastro da aplicação no Microsoft Entra ID;
- **Application factory:** função que cria a aplicação Flask;
- **Callback:** endpoint que recebe a resposta de autenticação;
- **Claims:** atributos validados da identidade;
- **Graph:** API Microsoft Graph;
- **Identity:** representação externa do usuário autenticado;
- **MSAL:** Microsoft Authentication Library;
- **Readiness:** capacidade de receber tráfego;
- **Liveness:** processo está vivo;
- **Scope:** permissão delegada para API;
- **Session fixation:** reutilização indevida de identificador de sessão;
- **State:** proteção que associa login e callback;
- **Tenant:** diretório Microsoft Entra;
- **Token cache:** cache gerenciado pelo MSAL;
- **WSGI:** interface de execução de aplicações Python web.
